Storage

-
ReSkate keeps its own merged copy, so real disk use can be up to about double.

Last check

-
"Check for changes" downloads and inspects candidates but changes nothing. "Sync now" installs them - close the ReSkate launcher and the game first. New cosmetics load the next time you start the game.

Storage limit

-
Space for synced cosmetics; your own mods do not count.

Biggest single mod

-
Bigger packs are skipped.

What gets added

Tap to switch a type on or off. A mod that has anything you switched off is skipped completely. "Your skater" types can change how you look, so skin, face and body start off.
